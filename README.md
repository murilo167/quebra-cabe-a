# quebra-cabeça
# 🧩 Quebra-Cabeça Interativo com JavaScript

Projeto desenvolvido para a disciplina **Programação Website I**, com o objetivo de praticar conceitos fundamentais de **HTML, CSS e JavaScript**, focando principalmente na manipulação do **DOM (Document Object Model)**.

---

## 🎯 Objetivo

Criar uma interface interativa onde o usuário:

* ativa uma peça do “quebra-cabeça”
* visualiza mudanças dinâmicas na tela
* acessa o conteúdo da aula ao interagir com a peça

---

## 🚀 Funcionalidades

✔ Botão que ativa a peça
✔ Alteração dinâmica de texto, cor e estilo
✔ Troca de ícone (🔒 → 🔓)
✔ Mudança de estado (bloqueada → ativa)
✔ Redirecionamento para página de conteúdo
✔ Interface responsiva

---

## 🧠 Conceitos Aplicados

* Manipulação do DOM
* Eventos (`addEventListener`)
* Alteração de conteúdo (`innerText`)
* Manipulação de classes (`classList`)
* Condições (`if`)
* Variáveis em JavaScript

---

## 🛠️ Tecnologias Utilizadas

* HTML5
* CSS3
* JavaScript (Vanilla JS)

## ▶️ Como Executar

1. Baixe ou clone este repositório
2. Abra o arquivo `index.html` no navegador
3. Clique no botão **"Ativar Peça"**
4. Clique na peça desbloqueada para acessar a aula

---

## 🔗 Fluxo do Projeto

1. Usuário clica no botão
2. JavaScript altera o estado da peça
3. Interface é atualizada dinamicamente
4. Peça se torna clicável
5. Usuário é redirecionado para a página da aula

---
