Introdução ao JavaScript + DOM

Objetivo da Aula

  • Entender o papel do JavaScript no navegador
  • Compreender o que é o DOM
  • Acessar elementos da página
  • Reagir a eventos do usuário
  • Alterar conteúdo dinamicamente

O que é o DOM?

DOM = Document Object Model

É a estrutura que representa o HTML dentro do navegador.

Exemplo

BODY
 ├── H1
 └── BUTTON

Conclusão

JavaScript manipula o DOM — não diretamente o HTML.
